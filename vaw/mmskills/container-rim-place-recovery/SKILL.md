# Container Rim Place Recovery

## When to use

已抓持物在放入开口容器时接触或挤压边沿，或者容器已经被碰歪。

## Visual question

当前被抓物是否已与容器边沿完全分离；分离后，其水平投影是否位于当前可见开口内部并接近中部？

## Adjustment principle

先沿 base +Z 小幅上抬，每次只依据新画面判断；一旦被抓物与边沿出现清晰间隙就停止上抬。随后只沿
base X/Y 做最小调整，使被抓物的水平投影进入开口中部。除维持释放净空外，不用 Z 追求完美对齐。

## Stop and verification

被抓物与边沿有清晰间隙且水平投影落在有效开口内部时即可准备释放；释放后仍以新的真实画面核验结果。

# GPT5.5 vs Qwen3.5-Plus 静态诊断基线

## 设置

- 数据集：`static_vlm_cases.json`，10 题，每题一张完整 VAW Context PNG。
- 输入：固定诊断 System Prompt、单张图片和一道选择题。
- 排除：Agent Task Prompt、manifest、Function List、History 和环境真值。
- 模型：`vapi/gpt-5.5`、`vapi/qwen3.5-plus`。
- 解码：temperature 0，每题运行一次。
- 完整机器可读结果：
  `vaw/out/static_vlm_diagnostics/gpt55_vs_qwen35plus_20260810_live/`。

## 结果

| Model | Accuracy | Median latency | Request errors |
|---|---:|---:|---:|
| `vapi/gpt-5.5` | 9/10 | 7.84 s | 0 |
| `vapi/qwen3.5-plus` | 10/10 | 19.87 s | 0 |

GPT5.5 唯一错误是 `grasp_state_01`。该图中蓝黄罐仍留在桌面、夹爪已闭合但没有形成有效
夹持。GPT5.5 选择“已抓住”，并声称罐体已经离地且位于两指之间；Qwen3.5-Plus 则正确引用
agentview 与 JAW PLANE，判断物体仍在支撑面、未被两指包围。

这与完整 Agent Loop 中最困扰的问题同型：即便移除 History、Function 描述和任务流程诱导，
GPT5.5 仍可能把“夹爪靠近/闭合”和“物体已受约束”合并为同一事实。因此该失败不能仅归因于
System Prompt；至少还包含模型对遮挡、局部点云与夹持几何的视觉归因错误。

## 不能过度解释的部分

- 只有 10 题且每题只运行一次，不是统计性 benchmark。
- 选择题比开放式 Agent 决策更容易；10/10 不代表 Qwen 在长轨迹中不会失败。
- 诊断 Prompt 明确要求区分 observed/preview 和命令/物理效果，测量的是“被要求注意后能否看懂”，
  不是模型是否会在自由决策中主动检查这些证据。
- Qwen 的若干正确回答仍出现目标身份表述不稳定，说明“选择正确”与“视觉证据完全可靠”不是一回事。

## 下一步建议

在改 Canvas 或继续加长 Agent Prompt 前，先扩展两个正交小集合：

1. 同一状态的 `full canvas / agentview-only / gripper-local-only` 三种裁剪，定位是哪一路视觉证据造成误判；
2. 同一抓取的 `close 前 / close 后 / lift 后` 三帧序列，但仍逐帧独立询问，测量随动证据何时足够。

如果 GPT5.5 只在 full canvas 失败，而 agentview-only 正确，问题主要是信息竞争；如果三种视图都失败，
则更像基础视觉几何能力或图像域偏差，继续堆提示文字的收益会很有限。
